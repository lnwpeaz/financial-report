# Slip to Excel 1.4

โปรแกรม Windows ออฟไลน์ อ่านสลิปทั้งโฟลเดอร์แล้วเพิ่มลง Excel เดิม ไม่ต้องกรอกครบหรือยืนยันทีละใบก่อนส่งออก

## ใช้งานทุกวัน

1. แตก `release/SlipToExcel-Windows-x64.zip` แล้วเปิด `SlipToExcel.exe`
2. กด **เพิ่มรูปสลิป** หรือ **เพิ่มทั้งโฟลเดอร์** เลือกภาพจากที่ใดก็ได้ รวมโฟลเดอร์ย่อย
3. โปรแกรมคัดลอกรูปเก็บใน `data/วันที่/รอบนำเข้า` อ่านและเพิ่มลง `report.xlsx` เดิมทันที
4. รอ **บันทึกสำเร็จ** แล้วกด **เปิด Excel ของฉัน** วันถัดไปทำแบบเดิม ไม่ต้องลบรูปเก่า

ปิดไฟล์ Excel ก่อนเพิ่มข้อมูล รูปเดิมข้ามให้ ชื่อไฟล์ซ้ำแต่คนละภาพไม่เขียนทับกัน หาก Excel เปิดค้าง ผลอ่านยังอยู่ให้กดบันทึกใหม่ได้

หน้าหลักแสดงยอดสะสม แท็บ **ประวัติใน Excel** อ่านจากรายงานจริงและค้นวันที่/ไซต์/ชื่อ/บันทึกได้ รายการที่ส่งออกแล้วไม่อยู่ในคิวรอ จึงแยกให้เห็นชัดว่าบันทึกแล้วหรือยัง

ชีต **รายการสลิป** มี date, site, ผู้รับ, ผู้ส่ง, จำนวนเงิน, หมายเหตุ / บันทึกความจำ ส่วนชีต **ตรวจสอบ** มีลิงก์รูปและข้อสังเกต ช่องที่อ่านไม่ได้เว้นว่าง และไม่ต้องยืนยันทีละใบก่อนส่งออก

ยังคัดลอกรูปลง `data` เองได้ แล้วใช้ **ใส่รูปใน data แล้ว? อ่านและบันทึก** หรือเปิดตัวเลือกอ่านทุก 15 วินาที หากต้องการตรวจแก้ก่อนส่งออก ใช้แท็บ **รอลง Excel / ตรวจแก้** และปุ่มอ่านสลิปในแท็บนั้น

ตั้งชื่อไซต์และเปลี่ยนโฟลเดอร์งานได้ในเมนูตั้งค่า โปรแกรมจำโฟลเดอร์ที่เลือกใน `app-settings.json` ข้าง EXE การเลือก `data` ภายในงานเดิมจะกลับไปโฟลเดอร์แม่ ป้องกันสร้างงานซ้อน

สำรองงาน/ย้ายเครื่องให้คัดลอกโฟลเดอร์งานทั้งชุด รวม EXE, report.xlsx, data, sites.json, .slipreport โปรแกรมยังสำรอง Excel ก่อนเพิ่มแต่ละรอบใน backups
ส่งโปรแกรมเปล่าให้คนอื่นใช้ ZIP ใน release ไม่ต้องส่งโค้ดหรือสลิปของผู้ใช้ ดูรายละเอียดในคู่มือการใช้งาน.txt

## รุ่น 1.4

ปรับหน้าหลัก นำเข้าภาพจากภายนอกและบันทึกในขั้นตอนเดียว ประวัติพร้อมค้นหา ความคืบหน้า/การหยุด/บันทึกซ้ำหลัง Excel ล็อก และจำโฟลเดอร์งาน โมเดลกับกฎอ่านสลิปคงเดิมจากรุ่น 1.3

## รุ่น 1.3

- ใช้โมเดล PP-OCRv5 ภาษาไทยผ่าน RapidOCR / ONNX Runtime อ่านชื่อและบันทึกซ้ำด้วยขอบภาพต่างกันเพื่อเก็บสระ/วรรณยุกต์
- ใส่ผลที่อ่านได้ให้ก่อน ไม่ล้างยอดเพียงเพราะตัวอ่านอีกวิธีให้ค่าต่างกัน ข้อสงสัยแสดงในหน้าจอและชีตตรวจสอบ
- อ่านบันทึก ข้อความประกอบภาพ และชื่อสั้น เช่น เอไอเอส เพิ่มเติม
- รายการรอส่งออกจากรุ่นเก่าจะอ่านใหม่เมื่อกดสแกน ปุ่ม **อ่านใหม่เฉพาะรายการที่รอ** อ่านรายการที่ยังไม่ยืนยัน/ส่งออกอีกครั้ง เก็บช่องที่ผู้ใช้แก้เองหรือตั้งใจล้างว่างไว้ สำรอง cache ก่อนเริ่ม
- การยืนยันแต่ละรายการเป็นทางเลือกเพื่อทำเครื่องหมายว่าตรวจแล้ว ไม่ใช่เงื่อนไขส่งออก
- ใบเสนอราคาใช้ยอดรวมสุทธิและมีคำเตือนว่าไม่ใช่หลักฐานชำระเงิน ภาพเงินสด/หลักฐานอื่นส่งออกได้โดยเว้นข้อมูลที่ไม่มี

การอ่านใหม่ไม่แก้แถวที่ส่งออก Excel แล้ว แก้รายการเหล่านั้นใน Excel ได้โดยตรง โปรแกรมรักษาค่าเดิมเมื่อเพิ่มสลิปใหม่ อย่าลบชีตซ่อน _imports ซึ่งเก็บประวัติกันซ้ำ

## ไซต์งาน

รายชื่อเริ่มต้น **สยาม (SI), นนท์, หัวหิน** เปลี่ยนหรือเพิ่มได้ใน **ตั้งชื่อไซต์ / คำย่อ** และ sites.json โดย SI = สยามได้รับการยืนยันจากผู้ใช้

ค้นชื่อ/คำย่อจากบันทึก คำระบุไซต์ และข้อความประกอบนอกส่วนชื่อผู้ส่ง/ผู้รับ รองรับ “งานนนท์” ที่เขียนติดกัน ไม่เอาชื่อคนมาเลือกไซต์ และไม่เหมารวมจากชื่อโฟลเดอร์ หากมีหลายไซต์หรือไม่มีข้อมูลพอ ช่องไซต์ยังว่างได้

คำย่อที่ไม่รู้ความหมายอาจเก็บตามภาพเมื่อมีบริบทไซต์ ไม่ขยายเป็นชื่อสถานที่โดยเดา รายชื่อเริ่มต้นเป็นกฎจับคู่ ไม่ใช่ความสามารถรู้จักทุกสถานที่

## ความแม่นยำและความเป็นส่วนตัว

ใช้โมเดลสำเร็จรูปที่ฝึกภาษาไทยมาแล้วร่วมกับการปรับวิธีอ่านและแยกช่อง ไม่ได้ฝึกน้ำหนักโมเดลใหม่จากสลิปผู้ใช้ และไม่ฝังคำตอบของไฟล์ตัวอย่างไว้ในโปรแกรม

ข้อมูลครบไม่เท่ากับถูกต้องทั้งหมด ชื่อคน วรรณยุกต์ ข้อความเล็ก ลายมือ และภาพรูปแบบใหม่ยังอ่านผิดได้ ผลอัตโนมัติถูกระบุว่ายังไม่ได้ตรวจในชีตตรวจสอบ โปรแกรมไม่ตรวจความแท้ของสลิป รองรับหนึ่งสลิปต่อรูปและเงินบาท ไม่รองรับ PDF/HEIC/รูปหลายหน้า

ไม่มี API key และไม่มีการส่งภาพหรือข้อความไปบริการออนไลน์ โมเดลและ runtime รวมอยู่ใน EXE ดาวน์โหลดเฉพาะตอนผู้พัฒนาเตรียม build

## พัฒนาและสร้าง EXE

ใช้ Windows x64 และ Python 3.13 ที่มีแพ็กเกจตาม requirements

```powershell
py -3 -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements-dev.txt
./scripts/bootstrap_ocr.ps1
.venv/Scripts/python.exe scripts/bootstrap_neural.py
.venv/Scripts/python.exe app.py
```

สร้างโปรแกรมและ ZIP สะอาดด้วย build.ps1 รวม OCR, โมเดล, runtime, คู่มือ และใบอนุญาต ไม่รวมสลิป รายงาน cache หรือการตั้งค่าส่วนตัว ถ้า EXE เก่ายังเปิดอยู่ จะวางรุ่นใหม่เป็น SlipToExcel-1.4.exe ข้างกันโดยไม่ปิดโปรแกรมของผู้ใช้

```powershell
.venv/Scripts/python.exe -m pytest -q
.venv/Scripts/python.exe app.py --self-test test-output/source-selftest.json
.venv/Scripts/python.exe app.py --workspace PATH --scan --export
```

--scan อ่านเข้าคิว, --export เพิ่มรายการทั้งหมดลง Excel โดยไม่ต้องยืนยัน, --refresh อ่านค่า OCR ใหม่เฉพาะรายการที่ยังไม่ยืนยัน/ส่งออก

slipreport/neural.py รับผิดชอบโมเดล/ตำแหน่งข้อความ, extract.py แยกข้อมูล, ocr.py มี Tesseract สำรอง, service.py จัดการอ่านต่อเนื่อง/cache, workspace.py คัดลอกรูป/ประวัติ/โฟลเดอร์งาน, storage.py บันทึก Excel แบบ atomic พร้อม lock/backup และป้องกันข้อความถูกตีความเป็นสูตร

แหล่งโมเดล: [PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR), [RapidOCR](https://github.com/RapidAI/RapidOCR) รุ่น/URL/checksum อยู่ใน build-manifest.json และ licenses/neural-models.json
