# SlipToExcel

**โปรแกรมอ่านสลิปธนาคารภาษาไทยเป็น Excel สำหรับงานค่าใช้จ่ายในองค์กร**

An offline Windows desktop application used in an organizational expense workflow to turn Thai bank-slip images into a continuously updated Excel report.

พัฒนาจากโจทย์และนำไปใช้งานจริงในองค์กรที่ต้องรวบรวมค่าใช้จ่ายจากหลายไซต์งาน ตั้งแต่การรับรูปสลิป อ่านข้อมูล จับคู่ไซต์ ไปจนถึงเพิ่มรายการใน Excel ไฟล์เดิม ออกแบบให้ผู้ใช้งานทั่วไปเปิดโปรแกรมและเพิ่มรูปได้ โดยไม่ต้องเขียนโค้ดหรือตั้งค่า API

**Windows 64-bit · Offline OCR · Thai language · Excel export · รุ่น 1.4.0**

[ดาวน์โหลดโปรแกรมพร้อมใช้](https://github.com/lnwpeaz/financial-report/releases/latest) · [คู่มือภาษาไทย](คู่มือการใช้งาน.txt) · [โค้ดและโครงสร้างระบบ](#โครงสร้างระบบ)

## ปัญหาจากงานจริง

ในงานรวบรวมค่าใช้จ่าย หลักฐานการโอนเงินมักอยู่ในรูปภาพหลายไฟล์และหลายโฟลเดอร์ ผู้รับผิดชอบต้องเปิดสลิปเพื่อคีย์วันที่ ผู้รับ ผู้ส่ง ยอดเงิน และบันทึกลง Excel ขณะเดียวกัน ชื่อไซต์อาจปรากฏเป็นคำย่อในบันทึก เป็นข้อความประกอบภาพ หรือไม่มีระบุเลย

โปรเจกต์นี้ช่วยนำข้อมูลที่อ่านได้เข้า Excel ก่อน พร้อมเก็บช่องว่างและข้อสังเกตสำหรับตรวจภายหลัง ทำให้การใช้งานประจำวันไม่ติดอยู่กับการกรอกข้อมูลให้ครบหรือยืนยันทุกใบ และยังเพิ่มสลิปวันถัดไปต่อในรายงานเดิมได้

ขอบเขตผลงานครอบคลุมการเชื่อมต่อโมเดล OCR การแยกข้อมูลจากตำแหน่งข้อความ การออกแบบหน้าจอ การจัดเก็บประวัติและกันภาพซ้ำ การบันทึก Excel อย่างปลอดภัย และการแพ็กเป็นโปรแกรม Windows สำหรับส่งต่อให้ผู้ใช้งาน

## การใช้งานประจำวัน

1. ดาวน์โหลด **SlipToExcel-Windows-x64.zip** จาก [Releases](https://github.com/lnwpeaz/financial-report/releases/latest) แล้วแตก ZIP ทั้งหมด
2. เปิด `SlipToExcel.exe` และปิด `report.xlsx` หากเปิดค้างอยู่ใน Excel
3. กด **เพิ่มรูปสลิป** หรือ **เพิ่มทั้งโฟลเดอร์** เลือกรูปได้หลายใบและรวมโฟลเดอร์ย่อยได้
4. โปรแกรมคัดลอกรูปเก็บไว้ในเครื่อง อ่านข้อมูล และเพิ่มต่อท้าย `report.xlsx` ให้โดยอัตโนมัติ
5. เมื่อขึ้น **บันทึกสำเร็จ** กด **เปิด Excel ของฉัน** หรือดูรายการในแท็บ **ประวัติใน Excel**

วันถัดไปทำขั้นตอนเดิมได้เลย ไม่ต้องสร้างรายงานใหม่หรือลบรูปเก่า ไม่ต้องติดตั้ง Python และไม่ต้องมี API key

หากคัดลอกรูปเข้า `data` เอง ให้กด **ใส่รูปใน data แล้ว? อ่านและบันทึก** หรือเปิดตัวเลือกตรวจรูปใหม่ทุก 15 วินาทีขณะที่โปรแกรมทำงาน สำหรับการตรวจแก้ก่อนส่งออก ใช้แท็บ **รอลง Excel / ตรวจแก้**

## ความสามารถหลัก

| ความสามารถ | พฤติกรรมในการใช้งาน |
|---|---|
| อ่านสลิปเป็นชุด | รับหลายรูปหรือทั้งโฟลเดอร์ รวมโฟลเดอร์ย่อย และคัดลอกเก็บโดยไม่ย้ายต้นฉบับ |
| แยกข้อมูล 6 ช่อง | วันที่ ไซต์ ผู้รับ ผู้ส่ง จำนวนเงิน และหมายเหตุ / บันทึกความจำ |
| จับคู่ไซต์จากบริบท | ใช้บันทึกและข้อความระบุไซต์ร่วมกับชื่อหรือคำย่อที่ตั้งไว้ เช่น `SI → สยาม` |
| รองรับข้อมูลไม่ครบ | บันทึกผลที่อ่านได้ ช่องที่ไม่มีข้อมูลยังว่าง และมีข้อสังเกตในชีตตรวจสอบ |
| ใช้รายงานเดิมต่อเนื่อง | เพิ่มต่อท้าย Excel รักษาค่าที่ผู้ใช้แก้ไว้ในรายการเดิม และสำรองไฟล์ก่อนเพิ่มข้อมูล |
| กันภาพซ้ำ | ตรวจทั้งแฮชไฟล์และแฮชพิกเซล มีข้อสังเกตเมื่อพบเลขอ้างอิงซ้ำ |
| ดูประวัติและค้นหา | แสดงจำนวนที่บันทึกแล้ว ค้นวันที่ ไซต์ ชื่อ และบันทึกจากรายงานปัจจุบัน |
| จัดการงานที่ยังไม่เสร็จ | เก็บผลอ่านที่ยังไม่บันทึกไว้ เมื่อ Excel เปิดค้างสามารถปิดแล้วกดบันทึกใหม่ได้ |
| ใช้งานออฟไลน์ | โมเดล OCR และ runtime รวมอยู่ใน EXE การอ่านสลิปไม่ต้องส่งภาพไปบริการออนไลน์ |

การจับคู่ไซต์ใช้ข้อความบริเวณบันทึกหรือคำระบุสถานที่ ไม่เหมารวมจากชื่อโฟลเดอร์หรือคำที่ปรากฏในชื่อผู้ส่ง/ผู้รับ หากไม่มีหลักฐานพอหรือมีหลายไซต์กำกวม จะเว้นช่องไซต์ไว้ ผู้ใช้ปรับรายชื่อและคำย่อได้จากเมนูตั้งค่า

## ตัวอย่างผลลัพธ์

ชีต **รายการสลิป** มีคอลัมน์ต่อไปนี้ ตัวเลข ชื่อ และข้อความในตารางนี้เป็นข้อมูลสมมติทั้งหมด:

| date | site | ผู้รับ | ผู้ส่ง | จำนวนเงิน | หมายเหตุ / บันทึกความจำ |
|---|---|---|---|---:|---|
| 2026-11-01 | ไซต์ A | ร้านวัสดุตัวอย่าง | ผู้ส่งตัวอย่าง | 1,250.50 | ซื้อวัสดุ A01 |
| 2026-11-02 |  | ผู้รับตัวอย่าง | ผู้ส่งตัวอย่าง | 300.00 | ค่าขนส่ง |

ตัวอย่างแรกสมมติว่าตั้งค่า `ไซต์ A = A01` ไว้แล้ว ส่วนรายการที่ไม่ระบุไซต์ยังนำเข้าได้ตามปกติ วันที่ใช้วันที่บนสลิป ไม่ใช่วันที่เพิ่มรูปเข้าโปรแกรม

ชีต **ตรวจสอบ** เก็บชื่อไฟล์ต้นฉบับ ลิงก์เปิดรูป แถวที่เกี่ยวข้องในรายงาน สถานะการตรวจ และข้อสังเกต ช่องวันที่และยอดเงินที่อ่านได้บันทึกเป็นชนิดข้อมูลวันที่และตัวเลขใน Excel

แก้ข้อมูลที่ส่งออกแล้วใน Excel ได้โดยตรง จากนั้นกดรีเฟรชในหน้าประวัติของโปรแกรม อย่าเปลี่ยนหัวคอลัมน์หรือลบชีตซ่อน `_imports` ซึ่งเก็บประวัติกันซ้ำ

## ผลการตรวจและขอบเขตความแม่นยำ

ตัวอ่านในรุ่น 1.3 ซึ่งใช้ต่อในรุ่น 1.4 ผ่านการตรวจเทียบกับภาพจากชุดงานจริง 270 ภาพ โดยตรวจยอดเงินครบทุกภาพ และตรวจชื่อ บันทึก และไซต์จากตัวอย่าง 30 ภาพ:

| ข้อมูลที่ตรวจ | ตรงกับภาพ / จำนวนที่ตรวจ |
|---|---:|
| จำนวนเงิน | 270 / 270 |
| ผู้ส่ง | 30 / 30 |
| ผู้รับ | 28 / 30 |
| หมายเหตุ / บันทึกความจำ | 28 / 30 |
| ไซต์ | 30 / 30 |

**ผลนี้เป็นผลบนชุดที่ใช้พัฒนาและตรวจ ไม่ใช่ชุดทดสอบอิสระทั้งหมด และไม่ใช่การรับประกันความแม่นยำกับสลิปใหม่ทุกใบ** การเทียบข้อความไม่นับช่องว่างและเครื่องหมายวรรคตอน แต่ยังนับความต่างของตัวอักษรและวรรณยุกต์ ผลไซต์รวมกรณีที่ควรเว้นว่างด้วย จึงไม่เท่ากับการรู้จักชื่อไซต์ได้ทุกกรณี

ชุดข้อมูลมีทั้งสลิปธนาคารและภาพหลักฐานค่าใช้จ่ายรูปแบบอื่น บางภาพไม่มีชื่อหรือวันที่ให้ดึงตั้งแต่ต้น จุดที่ยังพบความคลาดเคลื่อน ได้แก่ วรรณยุกต์ในชื่อ ข้อความขนาดเล็ก และชื่อผู้รับที่ปรากฏเฉพาะในโลโก้ ภาพและคำตอบรายรายการขององค์กรไม่เผยแพร่ใน repository นี้

ตัวแอปรุ่น 1.4 ผ่าน **98 automated tests** รวมถึงการนำเข้าซ้ำ การเพิ่มข้อมูลต่อใน Excel การรักษาค่าที่แก้เอง การสำรองข้อมูล การบันทึกล้มเหลว ไฟล์ Excel ถูกล็อก และขั้นตอนใช้งานผ่านหน้าจอ มีการทดสอบ OCR และการส่งออกจาก EXE ที่แพ็กแล้วด้วย

## แนวทางออกแบบ

- **อ่านให้ก่อน ตรวจแก้ได้ภายหลัง:** ข้อมูลบางช่องที่อ่านไม่ได้ไม่ทำให้ทั้งรายการถูกตัดออก ใช้ช่องว่างและข้อสังเกตแทนการเดาค่า
- **แยกหน้าที่ของ OCR กับการแปลผล:** ใช้โมเดลตรวจและอ่านข้อความ แล้วใช้ตำแหน่งข้อความ ป้ายกำกับ และบริบทของสลิปช่วยแยกช่องข้อมูล
- **เก็บข้อมูลในเครื่อง:** รูป รายงาน และแคชอยู่ในโฟลเดอร์งาน ส่วนการดาวน์โหลดโมเดลเกิดในขั้นตอนเตรียมเครื่องพัฒนาและ build
- **รักษารายงานเดิม:** เขียนไฟล์ชั่วคราว ตรวจว่า Excel ไม่ได้เปลี่ยนระหว่างทำงาน สำรองฉบับก่อนหน้า แล้วจึงแทนที่ไฟล์ปลายทาง
- **รองรับคนที่ไม่ได้เขียนโปรแกรม:** รวมโมเดลและ runtime ใน EXE มีปุ่มเพิ่มรูปและเปิดรายงาน พร้อมข้อความแยกสถานะรอบันทึกกับบันทึกแล้ว

ใช้โมเดลภาษาไทยที่ฝึกไว้แล้วร่วมกับการปรับกระบวนการอ่านและแยกข้อมูล **ไม่ได้ฝึกน้ำหนักโมเดลใหม่ด้วยสลิปขององค์กร และไม่มีการฝังคำตอบรายไฟล์ไว้ในโปรแกรม**

## ข้อจำกัดที่ควรรู้

- รองรับ JPG/JPEG, PNG, WEBP, BMP และ TIFF แบบหนึ่งสลิปต่อรูป ไม่รองรับ PDF, HEIC หรือภาพหลายหน้า
- ออกแบบสำหรับเงินบาท ไม่ใช่ระบบบัญชีหลายสกุลเงิน
- ภาพไม่ชัด ลายมือ วรรณยุกต์ และรูปแบบสลิปที่ไม่เคยตรวจอาจอ่านผิดได้ ควรตรวจข้อสังเกตก่อนนำรายงานไปใช้งานต่อ
- การกันภาพซ้ำไม่ได้รับประกันว่าจะจับภาพที่ถ่ายใหม่ ครอป หรือแก้ไขแล้วได้ทั้งหมด
- ชื่อไซต์ต้องมีข้อความหรือบริบทให้จับคู่ โปรแกรมไม่สามารถทราบไซต์จากสลิปที่ไม่มีข้อมูลนั้น
- ไม่ตรวจความแท้ของสลิปและไม่เชื่อมต่อกับธนาคารเพื่อยืนยันธุรกรรม
- เป็นเครื่องมือเดสก์ท็อปสำหรับโฟลเดอร์งานบนเครื่อง ไม่ใช่ระบบฐานข้อมูลกลางที่หลายคนแก้ไขพร้อมกัน

## สำหรับผู้พัฒนา

สภาพแวดล้อมที่ใช้พัฒนาและทดสอบ: **Windows x64, Python 3.13**

```powershell
git clone https://github.com/lnwpeaz/financial-report.git
cd financial-report
py -3.13 -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements-dev.txt
./scripts/bootstrap_ocr.ps1
.venv/Scripts/python.exe scripts/bootstrap_neural.py
.venv/Scripts/python.exe app.py
```

การเตรียม dependencies และโมเดลครั้งแรกต้องใช้อินเทอร์เน็ต หลังเตรียมครบแล้ว การอ่านสลิปทำงานในเครื่อง รุ่นและ checksum ของโมเดลกำหนดไว้ในสคริปต์ bootstrap

ทดสอบและสร้าง EXE:

```powershell
.venv/Scripts/python.exe -m pytest -q
.venv/Scripts/python.exe app.py --self-test test-output/source-selftest.json
./build.ps1
```

ชุดแจกจ่ายอยู่ที่ `release/SlipToExcel-Windows-x64.zip` สคริปต์ build รันชุดทดสอบและรวมโมเดล runtime คู่มือ และใบอนุญาตของส่วนประกอบ โดยไม่รวมข้อมูลการใช้งานของผู้ใช้

ใช้งานผ่าน CLI ได้เช่นกัน:

```powershell
.venv/Scripts/python.exe app.py --workspace "C:/SlipWork" --scan --export
```

`--scan` อ่านภาพใน `data` ของโฟลเดอร์งาน, `--export` เพิ่มรายการที่รอลง Excel โดยไม่ต้องยืนยันทีละใบ และ `--refresh` อ่านค่าอัตโนมัติใหม่เฉพาะรายการที่ยังไม่ยืนยันหรือส่งออก โดยเก็บช่องที่ผู้ใช้แก้เองไว้

## การเก็บข้อมูลและย้ายเครื่อง

โฟลเดอร์งานประกอบด้วย `data`, `report.xlsx`, `sites.json`, `.slipreport` และ `backups` หากต้องการย้ายงานเดิม ให้ปิดโปรแกรมกับ Excel แล้วคัดลอกโฟลเดอร์งานทั้งชุดพร้อม EXE ไปเครื่องใหม่ หากต้องการเปิดจาก Desktop ให้สร้าง Shortcut ไปยัง EXE ในโฟลเดอร์งาน

Repository นี้เผยแพร่โค้ด คู่มือ และชุดทดสอบ ภาพสลิปจริง รายงานขององค์กร แคช และผลตรวจที่มีข้อมูลรายรายการถูกแยกออกจาก Git และไฟล์ดาวน์โหลด
