สลิปเป็น Excel รุ่น 1.4 — ใช้ไฟล์เดิมได้ทุกวัน

เริ่มใช้
1. แตก ZIP ก่อน แล้วดับเบิลคลิก SlipToExcel.exe
2. กด “เพิ่มรูปสลิป” เลือกได้หลายรูป หรือ “เพิ่มทั้งโฟลเดอร์” รวมโฟลเดอร์ย่อยได้
3. รอข้อความ “บันทึกสำเร็จ” แล้วกด “เปิด Excel ของฉัน”
ไม่ต้องติดตั้ง Python ไม่ต้องสมัคร API ใช้งานออฟไลน์

วันถัดไปทำอย่างไร
ปิด report.xlsx ถ้าเปิดอยู่ แล้วกดเพิ่มรูปแบบเดิมได้เลย โปรแกรมเพิ่มต่อท้าย Excel ไฟล์เดิม
ไม่ต้องลบรูปเก่า ไม่ต้องตั้งค่าทุกวัน และไม่ต้องยืนยันสลิปทีละใบ
ถ้าคัดลอกรูปเข้า data เอง ให้กด “ใส่รูปใน data แล้ว? อ่านและบันทึก” ที่หน้าหลัก
มีตัวเลือกอ่านและบันทึกรูปใหม่ใน data ทุก 15 วินาที เฉพาะขณะเปิดโปรแกรม

ไฟล์ถูกเก็บที่ไหน
โฟลเดอร์ข้าง SlipToExcel.exe เป็นที่เก็บงานปกติ:
  report.xlsx   รายงานสะสมที่ใช้ต่อทุกวัน
  data          รูปที่คัดลอกมา แยกตามวันนำเข้าและรอบนำเข้า
  sites.json    ชื่อไซต์และคำย่อ
  .slipreport   ผลที่อ่านไว้และการแก้ไขที่ยังไม่ลง Excel
  backups       Excel รุ่นก่อนหน้า สำรองก่อนเพิ่มข้อมูล
วันที่ในคอลัมน์ date คือวันที่บนสลิป ไม่ใช่วันที่คัดลอกภาพเข้าโปรแกรม
โปรแกรมคัดลอกภาพ ต้นฉบับในมือถือ/โฟลเดอร์ที่เลือกยังอยู่ที่เดิม
รูปชื่อเหมือนกันแต่คนละใบเก็บได้ ไม่เขียนทับกัน

ดูรายการที่บันทึกแล้ว
หน้าหลักบอกยอดสะสมใน Excel แท็บ “ประวัติใน Excel” ดูและค้นวันที่ ไซต์ ชื่อ หรือบันทึกได้
ดับเบิลคลิกแถวเพื่ออ่านข้อความเต็ม ถ้าแก้ Excel เองให้กด “รีเฟรชจาก Excel”
แท็บ “รอลง Excel / ตรวจแก้” มีเฉพาะรายการที่ยังไม่บันทึก พอบันทึกแล้วรายการจะไปอยู่ในประวัติ
คิวว่างจึงไม่ใช่ข้อมูลหาย

ข้อมูลใน Excel
ชีต “รายการสลิป” มี date, site, ผู้รับ, ผู้ส่ง, จำนวนเงิน, หมายเหตุ / บันทึกความจำ
ชีต “ตรวจสอบ” มีไฟล์ต้นฉบับ ลิงก์เปิดรูป สถานะการตรวจ และข้อสังเกต
ช่องที่ไม่มีข้อมูลหรืออ่านไม่ได้จะว่าง ไม่ใช้ยอด 0 แทน และยังนำรายการนั้นลง Excel ได้
แก้ข้อความ/ยอดที่บันทึกแล้วใน Excel ได้เลย โปรแกรมรักษาการแก้ไขเมื่อเพิ่มรายการใหม่
อย่าเปลี่ยนหัวคอลัมน์ และอย่าลบชีตซ่อน _imports ซึ่งใช้กันซ้ำ

ไซต์งาน
เริ่มต้นมี สยาม (SI), นนท์, หัวหิน ปรับได้ใน “ตั้งค่า / โฟลเดอร์งาน” > “ชื่อไซต์ / คำย่อ”
ตัวอย่างบันทึก “SI ซื้อสี” จะได้ไซต์ สยาม; “งานนนท์” จะได้ นนท์
เลือกไซต์จากบันทึก/ข้อความระบุสถานที่ ไม่เลือกจากชื่อผู้ส่งผู้รับหรือเหมาเอาจากชื่อโฟลเดอร์
ถ้าไม่มีข้อความบอกไซต์หรือกำกวมจะเว้นว่าง ไม่จำเป็นต้องกรอกเพื่อบันทึก Excel

การอ่านและกันซ้ำ
ใช้ PP-OCRv5 ภาษาไทยแบบออฟไลน์ รุ่น 1.4 ใช้ตัวอ่านเดียวกับรุ่น 1.3
ตัวเลข ชื่อ วรรณยุกต์ และลายมือยังอ่านผิดได้ โดยเฉพาะรูปไม่ชัดหรือรูปแบบใหม่
อ่านผลให้ก่อนและระบุว่ายังไม่ได้ตรวจในชีตตรวจสอบ ไม่ใช่การรับรองความถูกต้องหรือความแท้ของสลิป
รองรับ JPG/JPEG, PNG, WEBP, BMP, TIFF หนึ่งสลิปต่อรูปและเงินบาท
ไม่รองรับ PDF, HEIC, ZIP/RAR หรือภาพหลายหน้า ต้องแปลงหรือแตกไฟล์เป็นรูปก่อน
กันซ้ำจากไฟล์และพิกเซลเดียวกัน แม้เปลี่ยนชื่อไฟล์ รูปถ่ายใหม่หรือภาพครอปอาจไม่ถือเป็นภาพเดียวกัน
เลขอ้างอิงซ้ำมีข้อสังเกตให้ตรวจ ไม่ตัดทิ้งอัตโนมัติ

ถ้าบันทึกไม่ได้
ปิด report.xlsx ใน Excel แล้วกด “บันทึกรายการที่รอ” ไม่ต้องอ่านรูปใหม่
กด “ดูบันทึก” เพื่อดูไฟล์ที่เปิดไม่ได้หรือคัดลอกไม่สำเร็จ
กด “หยุด” ระหว่างอ่านได้ รูปและผลที่อ่านแล้วเก็บอยู่ กดบันทึกรายการที่รอหรือเพิ่มรูปต่อภายหลัง
อย่าลบหรือเปลี่ยนชื่อ report.xlsx หากต้องการใช้รายงานเดิมต่อ

สำรอง ย้ายเครื่อง และส่งให้คนอื่น
สำรองงาน: ปิดโปรแกรมกับ Excel แล้วคัดลอกโฟลเดอร์งานทั้งโฟลเดอร์ไปอีกไดรฟ์
ส่งโปรแกรมเปล่า: ส่ง SlipToExcel-Windows-x64.zip ให้ผู้รับแตก ZIP และเปิด EXE
ย้ายงานเดิม: คัดลอกโฟลเดอร์งานทั้งโฟลเดอร์ รวม EXE, report.xlsx, data, sites.json, .slipreport
ไม่ต้องส่งโฟลเดอร์โค้ด financial-report ทั้งหมด
หากเคยเลือกโฟลเดอร์งานภายนอก โปรแกรมจะจำที่นั้นไว้ เมื่อต้องย้ายเครื่อง ให้ใช้โฟลเดอร์ที่มีรายงานเป็นหลัก

เปลี่ยนชุดงาน
ปกติไม่ต้องเปลี่ยน ใช้รายงานเดิมไปเรื่อย ๆ ได้
เมื่อต้องการรายงานอีกชุด ใช้ “ตั้งค่า / โฟลเดอร์งาน” > “เปลี่ยนโฟลเดอร์งาน”
เลือกโฟลเดอร์แม่ที่มี report.xlsx และ data โปรแกรมจำไว้เมื่อเปิดครั้งต่อไป
ถ้าเผลอเลือก data ภายในงานเดิม โปรแกรมจะกลับไปใช้โฟลเดอร์แม่ให้อัตโนมัติ
